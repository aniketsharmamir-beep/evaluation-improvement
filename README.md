# Model Evaluation and Performance Improvement: Titanic

## Objective
Compare six models using accuracy, precision, recall, F1-score, and cross-validation, and diagnose overfitting and underfitting.

## Files
- notebooks/model_evaluation.ipynb: evaluation and comparison
- data/performance_comparison.csv: performance comparison table
- docs/evaluation_report.md: metric selection and model strengths and weaknesses
- images/: comparison chart and confusion matrix
